第 1 周 · 路径与目录

手机读，电脑练 ｜ 11/16 开课 · 第 1 张

一、为什么要有「路径」

电脑里有上百万个文件。难的地方不是"打开一个文件"，是打开某一个特定的文件。

因为文件可以重名。你完全可以建 10 个都叫 笔记.txt 的文件，分别放在不同文件夹里。这时候你说"打开笔记.txt"，电脑不知道是哪一本。

所以光靠名字不够，还得靠位置。

一句话记住：名字可能重复，位置不会重复。
路径就是文件的位置——用位置唯一定位一个文件。

二、路径是什么

路径 Path

路径 = 从根出发，一层一层走到目标文件的完整路线。

看这个：

C:\Users\24281\学习\进度.md

从左往右读：C: → Users → 24281 → 学习 → 进度.md

就像快递地址：北京市 → 海淀区 → 中关村大街 1 号 → 302 室。少写一层，快递就送不到。

三个必须记住的词

词是什么WindowsLinux
根目录最顶层那一层C:\/
分隔符层与层之间的分隔\ 反斜杠/ 正斜杠
当前目录你现在"站"在哪个文件夹—

绝对路径 vs 相对路径

从哪开始写例子特点
绝对路径从根C:\Users\24281\学习\进度.md在哪都能用
相对路径从当前目录学习\进度.md换个当前目录就指错
绝对路径 = 完整快递地址；相对路径 = "从这儿往前走两个路口"。你站在别处说这句话，别人就找不到了。

三、目录是什么

目录 = 文件夹。同一个东西的两个名字，没有区别。

  • 根目录：最顶层的那个文件夹
  • 子目录：文件夹里面的文件夹（房间里的柜子）
  • 当前目录：你现在待着的那个文件夹

为什么"当前目录"重要？因为相对路径是相对它来算的。你站错房间，一伸手就摸错东西。

四、怎么做：看到路径的三步

  1. 看开头 → 判断系统
    C:\ 这种盘符 + 反斜杠 → Windows；
    / 开头、没有盘符 → Linux
  2. 从左往右读 → 一层一层说清每一层是什么
  3. 看是不是从根开始 → 判断绝对还是相对

五、扩展名不是身份证

你双击一个文件，电脑凭什么知道该用哪个程序打开它？

靠扩展名——文件名里最后一个点后面那一截。进度.md 的扩展名是 md，所以用编辑器打开；test.py 是 py，所以用 Python 跑。

关键在这：扩展名只是名字的一部分，不是文件的身份证。文件内容是一堆二进制，扩展名只是给人看的一个标签。

扩展名像快递箱子外面贴的标签：写着"易碎品"，箱子里装的也可能是书。
标签可以贴错——所以把 a.txt 改名成 a.jpg，它不会变成图片，只是画图软件打不开了。

一个真实的坑

Windows 默认隐藏已知类型的扩展名。于是 报销单.docx.exe 在你眼里显示成 报销单.docx——图标还是 Word 的。

你双击，运行的不是文档，是那个 .exe。

怎么做：资源管理器 → 顶部「查看」→ 勾选「文件扩展名」。（Win11 在「查看 → 显示 → 文件扩展名」）

六、以后在无人机里怎么用

这一周的东西看着像"电脑常识"，但它其实是后面所有事的地基：

以后你会碰到的这一周对应的概念
/home/你/ros2_ws/src —— 你每天 cd 的地方绝对路径、家目录 ~
ros2 launch px4 ... 报"找不到 launch 文件"相对路径 + 当前目录
PX4 的 .params、ROS2 的 package.xml、权重 .pt扩展名
Windows 训练好模型，搬到 WSL 里跑仿真两种路径写法、/mnt/c

一句预判：以后你遇到的"跑不起来"，一大半第一步都该问——"我现在站在哪个目录？"

七、自测（先自己想，再点开）

1. 用一句话说，路径是什么？

文件在电脑里的完整地址，从根一路写到文件名。

2. 「当前目录」为什么重要？

相对路径是相对当前目录算的。站错房间，就找不到文件。

3. 绝对路径和相对路径，最大的区别是什么？

绝对路径从根开始写，在哪都能用；相对路径从当前目录开始写，换个位置就指错。

4. 看到一个路径，怎么快速判断 Windows 还是 Linux？

看开头：盘符 + 反斜杠（C:\）= Windows；以正斜杠开头、没有盘符（/home）= Linux。

5. 把 照片.txt 改名成 照片.jpg，它变成图片了吗？

没有。扩展名只是标签，文件内容一个字节都没变，只是系统会拿画图软件去打开它，然后打不开。

6. 为什么"显示扩展名"这个设置值得改？

因为默认隐藏时，病毒.docx.exe 会显示成 病毒.docx，图标也是 Word 的。你看到的和实际运行的，不是一个东西。

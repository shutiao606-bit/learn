第 1 周 · Windows 路径 vs Linux 路径

你现在练的全是 Windows，以后干活全在 Linux ｜ 2026-11-13

一、为什么非要懂这个

PX4、ROS2、Gazebo —— 全都长在 Linux 上。你迟早要进 Ubuntu。

而你现在每天练的 C:\Users\24281\学习 那套写法，进了 Linux 一条都用不了。

更麻烦的是：两个系统都叫"路径"，长得有点像，所以你以为自己懂了，一贴进去就报 No such file or directory。

这张卡就是把它们摆在一起，看清楚哪里不一样。

二、最根本的区别：几栋楼 vs 一棵树

Windows：每个盘是一栋独立的楼。

C:\ 是一栋，D:\ 是一栋，E:\ 是一栋。各自有各自的根，互不相通。你要找 E 盘的东西，必须写 E:\...，不能从 C:\ 一路走过去。

Linux：只有一棵树。

根只有一个：/。硬盘、U 盘、移动硬盘、网络盘，全都是挂在这棵树某个枝头上的一块地方。

Windows 像几个独立仓库，每个仓库自己编号（C 仓、D 仓），仓库之间没有门。
Linux 像一个总仓库，只有一个大门，所有货物都从这扇门进去，分区只是"3 号货架"和"5 号货架"。
所以 Linux 里没有"盘符"这个概念，也不需要。

你写 import Numpy，Windows 上可能还能跑，Linux 上直接报错，因为真的包叫 numpy。以后跑 ROS2 的时候，这种错误一找就是半小时。

五、你这台电脑上的桥梁：WSL

你这台机器已经装了 WSL，终端列表里那两个 Ubuntu-22.04 就是它。也就是说：不用装双系统，你现在就能开 Linux。

WSL 里的 Linux 能看到 Windows 的盘，位置固定：

WindowsWSL 里写成
C:\Users\24281\学习/mnt/c/Users/24281/学习
D:\研究生/mnt/d/研究生
E:\研究生/mnt/e/研究生

规律：盘符变小写、塞进 /mnt/、反斜杠全改成正斜杠。

六、最容易踩的四个坑

  1. 把 C:\... 原样粘进 Linux → 找不到文件。要先翻译成 /mnt/c/...
  2. 在 Linux 里写 cd C:\Users → 反斜杠在 Linux 里是"转义符"，不是分隔符，整行意思全变
  3. 大小写随手写 → Desktop.txt 和 desktop.txt 在 Linux 里是两个不同文件
  4. 路径里有空格不加引号 → cd My Folder 会被当成两个参数，报"找不到 My"

七、自测（先自己想，再点开）

1. 为什么 Linux 没有 C 盘、D 盘？

因为 Linux 只有一棵树，根是 /。所有存储设备都是挂到这棵树的某个目录上，不需要用盘符区分。

2. ~/ros2_ws/src 展开成完整路径是什么？

~ 是你的家目录，也就是 /home/你的用户名，所以是 /home/你的用户名/ros2_ws/src。

3. 在 Windows 里写 cd D: 会发生什么？在 Linux 里写呢？

两者意义不同：Windows 的 D: 是切到 D 盘；Linux 里根本没有 D: 这种东西，会当成一个不存在的目录。

4. 为什么 Linux 对大小写这么较真？

Linux 的文件系统（ext4 等）本身就是区分大小写的，这是设计如此，不是 bug。Python 的模块名、ROS2 的包名也都遵循这个规则。

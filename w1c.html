第 1 周 · 进程是什么

程序跑起来之后，在电脑里变成了什么 ｜ 11/18 · 第 3 张

一、为什么非要懂这个

以后跑无人机仿真，你屏幕上会同时开三样东西：

  • PX4 —— 在算飞控、算姿态
  • Gazebo —— 在画那个三维世界
  • YOLO 检测节点 —— 在一帧一帧地看画面

其中一个卡死了，你要单独把它关掉、重启，别的不能动。可任务管理器里那一列名字你一个都不认识，只能全部关掉重来——十分钟又没了。

懂进程，你才知道该杀哪一个。

二、程序 ≠ 进程

程序 Program进程 Process
在哪硬盘上的一个文件内存里活着的一份
长什么样chrome.exe、train.py任务管理器里那一行
不跑的时候躺着，不占 CPU 内存不存在
能有几份就一个文件可以同时开很多份
程序 = 菜谱（印在纸上，放着不做就不产生任何东西）
进程 = 照着菜谱真正做出来的那盘菜（占着灶台、占着食材、做完就没了）
同一本菜谱可以做十盘菜 —— 同一个程序可以开十个进程。

一个程序开多个进程，很常见

  • Chrome 浏览器：每个标签页一个进程。所以一个标签崩了，别的还能用
  • Gazebo 你开两个窗口，任务管理器里就是两个进程
  • 你跑两次 python train.py，就是两个 Python 进程在抢显卡

反过来：看到三个 python.exe，不代表装了三个 Python。

三、进程身上带着什么

东西是什么在哪看
PID进程的身份证号，一个数字任务管理器 →「详细信息」那列 PID
CPU / 内存它现在占多少资源任务管理器主界面
状态在跑 / 在等 / 卡死「未响应」就是卡死
父进程是谁把它启动的结束父进程，子进程一般跟着死
PID 就像工牌号。你要让某个工人停手，不能喊"那个工人"，得喊工号：kill 4821。

四、怎么做：看到进程

Windows 图形界面：Ctrl + Shift + Esc 打开任务管理器 → 点「详细信息」标签 → 有 PID 那一列。

Windows 命令行：

tasklist —— 列出所有进程

Linux：

ps aux —— 列一次；top —— 实时刷新

结束一个进程：任务管理器里右键「结束任务」；Linux 里 kill PID。

五、对上你的项目

你看到的名字它在干什么关了会怎样
px4算飞机怎么飞飞机掉下来，Gazebo 里模型不动了
gzserver / gzclient仿真世界的后台 / 画面世界没了，但 PX4 还在空转
python（你的检测节点）跑 YOLO只有检测停，飞行不受影响

它们之间不是互相调用，而是各自独立跑、靠话题传消息。这就是为什么能单独重启一个 —— 这也是「集群」能成立的前提。

六、一个常见误解

「我把终端窗口关了，程序就停了吧？」

不一定。终端只是传话窗口，进程是工人。窗口关了，工人可能还在干（尤其是后台启动的）。

反过来更常见：进程卡死了，窗口关不掉——因为窗口在等工人回话，工人不应答。这时候只能去任务管理器结束进程。

七、进程怎么跟外界说话——端口

你电脑上同时跑着几十上百个进程，还有一大堆程序在往网络里收东西。那一条消息怎么才能送到对的那个进程手上？

靠端口（port）：一个 0 到 65535 的数字。进程启动时向系统申请一个端口，之后别人用「地址 + 端口」就能找到它。

127.0.0.1:8080 的意思是：本机（127.0.0.1）的 8080 号端口。

IP 地址是一栋楼，端口是房间号。
只知道楼号，快递员只能把东西扔在大厅；写上房间号，才能送到具体那间。

你会撞上的第一个报错：Address already in use（端口已被占用）。

原因几乎总是同一个：上一个进程没死干净，端口还被它占着。解决办法不是重启电脑，是找到那个进程杀掉。

系统查谁占了端口
Windowsnetstat -ano | findstr :8080
Linuxss -tlnp 或 lsof -i:8080

和上一节连起来看：查出来的那个数字就是 PID，拿它去 kill。进程、PID、端口，三样东西在这里接上了。

八、以后在无人机里怎么用

以后你会碰到的今天对应的概念
一个终端里 PX4、Gazebo、三个检测节点同时在跑程序 vs 进程、PID
Gazebo 卡死，只关它、不关 PX4每个节点是独立进程
起仿真时报 Address already in use端口
浏览器打开 localhost:8080 看 Gazebo 画面IP + 端口
ros2 node list 看到一堆节点名进程的另一种叫法

为什么要现在懂：以后仿真起不来，十次里有三次是「有个旧进程还赖在那儿」。会看进程和端口，你自己三分钟能解决；不会，就得重启电脑碰运气。

九、自测（先自己想，再点开）

1. 程序和进程，一句话区别是什么？

程序是硬盘上的文件，进程是它跑起来之后在内存里活着的那一份。

2. 任务管理器里有 5 个 chrome.exe，是中毒了吗？

不是。Chrome 每个标签页、每个插件都单开一个进程。

3. PID 是干什么用的？

进程的身份证号，用来精确指定"要停的是哪一个"。

4. 关掉终端窗口，里面跑的程序一定停吗？

不一定。终端是窗口，程序是进程，两回事。

5. 端口是什么？为什么光有 IP 地址不够？

端口是进程向系统申请的房间号。一台电脑上同时有很多程序在收发数据，光有楼号（IP）分不清该交给谁。

6. 报 Address already in use，第一步该干什么？

别重启电脑。先查是谁占着这个端口（netstat -ano | findstr :端口号），拿到 PID，把那个进程结束掉。

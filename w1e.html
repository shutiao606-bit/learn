一、为什么必须动手

前面几张卡你都读过了，那只是 L2：能复述。

这一周的电脑目标只有一件事：在终端里自由地走动，并且永远知道自己在哪。

二、只有三条命令

你想干什么Windows PowerShellcmd 命令提示符Linux
我在哪？pwdcdpwd
这里有什么？ls 或 dirdirls
去某个目录cd 路径cd 路径cd 路径

好消息：cd 和 cd .. 三个系统完全一样。你只在 Windows 上练，迁到 Linux 时这部分不用重学。

注意：PowerShell 里 ls 和 dir 都能用（它是 Get-ChildItem 的别名）。cmd 里只有 dir。

三、打开终端

方法一（推荐）：Win + X → 选「终端」或「终端(管理员)」

方法二：Win + R → 输入 powershell → 回车

方法三：在任意文件夹的地址栏里直接输入 powershell 回车 —— 终端会直接开在这个文件夹里，这个技巧以后很省事。

打开后默认位置一般是 C:\Users\24281。

四、五步走（每一步先猜，再看）

  1. 看自己在哪 —— 敲 pwd。
    先猜会打印什么，再看实际结果。
  2. 看这儿有什么 —— 敲 ls。
    找找有没有「学习」这个文件夹。
  3. 走进去 —— 敲 cd 学习，然后再 pwd 确认。
    如果 pwd 变了，说明你真的进去了。
  4. 再看一眼 —— ls，找 进度.md 在不在。
    在，就证明你这个"位置"是对的。
  5. 退回来 —— cd ..，再 pwd，应该回到 C:\Users\24281。
pwd 是看路牌，ls 是看货架，cd 是走进一扇门，cd .. 是往回走一层。
永远先看路牌，再走路。迷路的人都是不看路牌就开始走的。

五、Tab 补全：效率的分水岭

敲 cd 学，然后按 Tab 键 —— 会自动补成 cd 学习。

如果补全了，说明名字对；如果没反应或补成别的，说明你打错了。这是最便宜的纠错方式。

长路径尤其有用：cd C:\Users\24281\学习\site 敲成 cd C:\Us + Tab + 学 + Tab 就行。

已经敲错一个字母，Tab 救不了你 —— 它是补全，不是纠错。但它会立刻暴露你敲错了。

六、历史命令：别再重敲一遍

长路径敲错一个字母，就要从头再来一遍？一天下来手指头先废了。

shell 其实把你敲过的每一条命令都记着，就在这次会话里。会调用历史，是新手和老手最明显的分界线。

按键干什么
↑ / ↓上一条 / 下一条命令，翻出来直接回车
Ctrl + R输入几个字母，从历史里搜以这几个字母开头的命令
Ctrl + C放弃当前这行（还没回车），重来
Ctrl + L清屏（比 clear 快）

Windows PowerShell 和 Linux 都支持这几个键。cmd 里也有 ↑，但没有 Ctrl+R。

历史命令像手机的输入法联想：你不用把整句重新打一遍，按一下它就猜出来了。
敲错一个字母时，按 ↑ 翻回来改一个字母，比重敲快十倍。

七、三种报错，分别说明什么

报错中文意思问题出在
command not found找不到这个命令命令名打错，或这个程序不在 PATH 里
No such file or directory
找不到路径		找不到这个文件/目录路径写错了，或者你站的位置不对（相对路径）
Permission denied
拒绝访问		不让你干权限不够，需要管理员

练的时候报错是好事。每次报错，你就知道该看哪一层：

命令找不到 → 去看 PATH
路径找不到 → 先去 pwd 看自己站哪，再用 ls 看目标在不在

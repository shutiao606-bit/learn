本周热门

第 1 期 ｜ 2026-11-13 更新 ｜ 每周日刷新一次

这页是干什么的

一个人闷头学，最大的风险不是学得慢，是学了半年才发现方向早就变了。

所以每周花 10 分钟，看一眼无人机集群和具身智能这个圈子里，这周在发生什么。

三条规则：

  1. 只看和主线有关的，别的刷到也划走
  2. 不 clone、不安装、不跑。这页只是"知道你站在哪"
  3. 10 分钟到点就关，不追更

本期 5 条

1. aerial-autonomy-stack —— 集群仿真到真机的一站式栈

是什么：把 PX4/ArduPilot 的多机仿真、ROS2、YOLO 视觉、激光雷达、Jetson 部署串在一起的开源项目。

为什么和你有关：这几乎就是你 6 周之后要自己一步步搭出来的东西。现在先看一眼它的目录结构，你就知道终点长什么样，学基础的时候心里有底。

这周能做的：只看 README 的文件夹列表，5 分钟 ｜ GitHub

2. Langostino —— ROS2 + AI 的自主无人机参考平台

是什么：一个用 ROS2 搭的自主飞行参考实现，11 月 4 日还在更新。

为什么和你有关：它的价值不在代码，在目录怎么分：传感器、控制、规划、感知各放哪。以后你建自己的工作空间时，照着这个骨架走，少走半年弯路。

这周能做的：看它的顶层文件夹名，猜猜每个是干什么的 ｜ GitHub

3. FlowPilot —— 让无人机"边想边飞"的世界模型（北理工，11 月 2 日接收）

是什么：一篇把世界模型（world-action model）用在小无人机敏捷导航上的论文，作者来自北理工等，代码承诺开源。

为什么和你有关：这正是"集群 + 具身智能"的交汇地带——不是先感知再规划再控制的三段式，而是一个模型直接吐动作。跟你以后要碰的 VLA 是同一套思路。

这周能做的：只看摘要最后两行结论 ｜ arXiv

4. Xiaomi-Robotics-0 —— 开源的机器人大模型（背景补课）

是什么：小米今年 2 月开源的 VLA 模型，约 47 亿参数，Apache-2.0，权重公开。结构上是"视觉语言大脑 + 扩散动作专家"，专门为实时性做了优化。

为什么和你有关：这是国内目前最有代表性的开源 VLA 之一。知道它存在就够了——等你做到 VLA 小项目时，这类模型会是你的起点，而不是从零训练。

这周能做的：记住一句话——开源 VLA 已经是"拿来微调"，不是"从头造" ｜ arXiv

5. Psi-Zero —— 人形机器人的 VLA，RSS'26 收录

是什么：一个人形机器人 VLA 项目，基于 LeRobot 生态，训练和部署工具链一起开源。

为什么和你有关：你的课题里有双机械臂。人形 VLA 和双臂操作在"双手协调"这一层是通的，以后查资料时这是关键词之一。

这周能做的：知道 LeRobot 这个词，以后会反复见到 ｜ GitHub

一句话连回你这周

这五条看着离你很远，其实都站在同一个地基上：

上周你学的 PX4、Gazebo、YOLO 节点，都是独立进程，靠话题和端口互相说话。上面这些项目，说到底就是把这些进程组织得更好。

所以这周读 ③ 进程、④ 路径的时候，不用觉得"这跟无人机有什么关系"——关系就是：所有这些项目跑起来之后，你都要靠这几样本事去认它们、停它们、修它们。

怎么更新

每周日你打开电脑，我搜一遍当周的热门项目、论文和版本更新，挑 3～5 条写进这一页，然后推到 GitHub Pages。

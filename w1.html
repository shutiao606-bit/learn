第 1 周 · 路径与目录

手机读，电脑练 ｜ 2026-11-09

一、为什么要有「路径」

电脑里有上百万个文件。难的地方不是"打开一个文件"，是打开某一个特定的文件。

因为文件可以重名。你完全可以建 10 个都叫 笔记.txt 的文件，分别放在不同文件夹里。这时候你说"打开笔记.txt"，电脑不知道是哪一本。

所以光靠名字不够，还得靠位置。

一句话记住：名字可能重复，位置不会重复。
路径就是文件的位置——用位置唯一定位一个文件。

二、路径是什么

路径 Path

路径 = 从根出发，一层一层走到目标文件的完整路线。

看这个：

C:\Users\24281\学习\进度.md

从左往右读：C: → Users → 24281 → 学习 → 进度.md

就像快递地址：北京市 → 海淀区 → 中关村大街 1 号 → 302 室。少写一层，快递就送不到。

三个必须记住的词

词是什么WindowsLinux
根目录最顶层那一层C:\/
分隔符层与层之间的分隔\ 反斜杠/ 正斜杠
当前目录你现在"站"在哪个文件夹—

绝对路径 vs 相对路径

从哪开始写例子特点
绝对路径从根C:\Users\24281\学习\进度.md在哪都能用
相对路径从当前目录学习\进度.md换个当前目录就指错
绝对路径 = 完整快递地址；相对路径 = "从这儿往前走两个路口"。你站在别处说这句话，别人就找不到了。

三、目录是什么

目录 = 文件夹。同一个东西的两个名字，没有区别。

  • 根目录：最顶层的那个文件夹
  • 子目录：文件夹里面的文件夹（房间里的柜子）
  • 当前目录：你现在待着的那个文件夹

为什么"当前目录"重要？因为相对路径是相对它来算的。你站错房间，一伸手就摸错东西。

四、怎么做：看到路径的三步

  1. 看开头 → 判断系统
    C:\ 这种盘符 + 反斜杠 → Windows；
    / 开头、没有盘符 → Linux
  2. 从左往右读 → 一层一层说清每一层是什么
  3. 看是不是从根开始 → 判断绝对还是相对

五、自测（先自己想，再点开）

1. 用一句话说，路径是什么？

文件在电脑里的完整地址，从根一路写到文件名。

2. 「当前目录」为什么重要？

相对路径是相对当前目录算的。站错房间，就找不到文件。

3. 绝对路径和相对路径，最大的区别是什么？

绝对路径从根开始写，在哪都能用；相对路径从当前目录开始写，换个位置就指错。

4. 看到一个路径，怎么快速判断 Windows 还是 Linux？

看开头：盘符 + 反斜杠（C:\）= Windows；以正斜杠开头、没有盘符（/home）= Linux。
